Codex 소개
Codex는 OpenAI의 AI 코딩 에이전트입니다.
자연어로 요청하면 코드를 작성하고 수정하거나 설명할 수 있습니다.
프로젝트 파일을 살펴보고 여러 파일에 걸친 작업도 도와줍니다.
오류를 분석하고 해결 방법을 제안하며 문서 작성과 코드 검토도 지원합니다.
개발자는 Codex와 협업해 반복 작업을 줄이고 문제 해결에 집중할 수 있습니다.

Claude Code 소개
Claude Code는 Anthropic이 만든 AI 코딩 에이전트입니다.
터미널, VS Code·JetBrains 같은 IDE, 데스크톱 앱, 웹에서 사용할 수 있습니다.
자연어로 요청하면 코드베이스를 읽고 이해한 뒤 직접 파일을 수정합니다.
셸 명령 실행, 테스트 실행, git 커밋과 PR 작성까지 처리할 수 있습니다.
여러 파일에 걸친 리팩터링과 버그 수정도 단계별로 진행합니다.
MCP 서버, 훅, 슬래시 명령, 스킬로 기능을 확장할 수 있습니다.
CLAUDE.md 파일로 프로젝트 규칙과 맥락을 알려줄 수 있습니다.
권한 모드를 통해 어떤 작업을 허용할지 사용자가 제어합니다.
